01 — ÁREAS DE ESPECIALIZACIÓN

Explora las ramas de la ciberseguridad.

La ciberseguridad es un campo multidisciplinario compuesto por diferentes áreas de conocimiento. Explora cada una y descubre qué estudia, qué problemas aborda y qué habilidades requiere.

🌐
01

Seguridad de Redes

Se enfoca en proteger las redes informáticas, dispositivos y comunicaciones frente a accesos no autorizados, ataques y otras amenazas.

TCP/IP DNS Firewalls VPN IDS/IPS
🔐
02

Criptografía

Estudia las técnicas matemáticas utilizadas para proteger información mediante cifrado, hashing, firmas digitales y sistemas de claves.

AES RSA SHA-256 Hash PKI
💻
03

Seguridad de Sistemas

Busca proteger sistemas operativos, servidores y dispositivos mediante controles de acceso, configuración segura y hardening.

Linux Windows Hardening Permisos
🕵️
04

Hacking Ético / Pentesting

Consiste en evaluar sistemas de forma autorizada para identificar vulnerabilidades y ayudar a mejorar su seguridad.

Reconocimiento Enumeración Vulnerabilidades Reportes
🦠
05

Análisis de Malware

Estudia software malicioso para comprender su comportamiento, identificar indicadores de compromiso y desarrollar medidas defensivas.

Virus Ransomware Troyanos IOC
🔎
06

Informática Forense

Se encarga de identificar, preservar y analizar evidencias digitales relacionadas con incidentes o investigaciones.

Evidencia Logs Metadatos Timeline
🌍
07

Seguridad Web

Protege aplicaciones web y APIs frente a vulnerabilidades que pueden comprometer información o funcionalidades.

OWASP XSS SQLi CSRF APIs
🚨
08

Respuesta a Incidentes

Se ocupa de detectar, contener, investigar y recuperar sistemas después de un incidente de seguridad.

Detección Contención Erradicación Recuperación
☁️
09

Seguridad en la Nube

Protege infraestructura, aplicaciones, identidades y datos alojados en plataformas de computación en la nube.

AWS Azure IAM Cloud
👤
10

Gestión de Identidades y Accesos

Administra identidades digitales y determina qué usuarios pueden acceder a determinados recursos y bajo qué condiciones.

IAM MFA RBAC SSO
