MÓDULO 01

Introducción a la seguridad de redes

Las redes permiten que computadores, servidores, teléfonos, dispositivos IoT y otros sistemas intercambien información.

La seguridad de redes busca proteger esa comunicación y los recursos conectados frente a accesos no autorizados, interrupciones, manipulación de datos y otras amenazas.

🎯 Objetivo

Comprender los principios básicos que permiten proteger una infraestructura de red.

MÓDULO 02

Conceptos fundamentales

Antes de estudiar herramientas de seguridad, es necesario comprender algunos conceptos básicos.

🌐 Red

Conjunto de dispositivos conectados que pueden intercambiar información.

📍 Dirección IP

Identificador utilizado para localizar un dispositivo dentro de una red.

🚪 Puerto

Punto lógico utilizado por los servicios de red para establecer comunicaciones.

🛡️ Firewall

Sistema que controla el tráfico de red de acuerdo con determinadas reglas.

MÓDULO 03

Modelo TCP/IP

TCP/IP es un conjunto de protocolos que permite la comunicación entre dispositivos conectados a una red.

Aplicación HTTP · DNS · SMTP
Transporte TCP · UDP
Internet IP · ICMP
Acceso a red Ethernet · Wi-Fi
MÓDULO 04

IP y puertos

Las direcciones IP permiten identificar interfaces dentro de una red, mientras que los puertos permiten diferenciar servicios y aplicaciones.

PC → 192.168.1.10

Servidor web → 192.168.1.20:443

SSH → 192.168.1.20:22

MÓDULO 05

DNS

El Domain Name System (DNS) permite traducir nombres de dominio legibles por las personas en direcciones IP utilizadas por los sistemas.

MÓDULO 06

Firewalls

Un firewall puede aplicar reglas para permitir, bloquear o registrar determinados tipos de tráfico.

ALLOW HTTPS : 443
BLOCK Tráfico no autorizado
MÓDULO 07

VPN

Una VPN establece un túnel de comunicación protegido entre dispositivos o redes a través de una infraestructura de red existente.

MÓDULO 08

IDS e IPS

IDS

Detecta y genera alertas ante posibles actividades sospechosas.

IPS

Puede detectar determinadas amenazas y actuar para bloquearlas.
